# 🛍️ HYEONMALL

## ✒️ 개요
* 쿠팡을 클론한 e-commerce 서비시의 서버를 설계하고 구축합니다.
* 이 프로젝트는 다음과 같은 목표를 가집니다.
  * DDD 기반의 모듈화된 도메인 설계를 적용하여 유지보수성과 확정설을 높이고, 테스트 코드를 작성합니다.
  * 대규모 트래픽과 대용량 처리가 가능하도록 합니다.
  * 성능 최적화 및 확장성을 고려합니다.
  * CI/CD를 구성하여 빌드/테스트/배포를 자동화합니다.
